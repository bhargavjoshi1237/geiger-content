# Entertainment corpus v2

The user authorized implementation and a background Arctic Shift crawl for a broad entertainment audience. Content embeddings will be generated by the user later.

## Product behavior

- Six areas: Movies & TV, Anime & Manga, Gaming, Music, Sports, Creators & Internet Culture. Use a mix of global and Indian subjects without claiming population representativeness.
- Variable-sized subject lists replace the fixed 5×4×5 tree. Subjects are peers, never increasing expertise levels. Keep a depth-1 compatibility projection for the feed engine and allow independent content-type tags.
- Collect image/gallery posts dated August 1 through October 31, 2026, using UTC calendar boundaries. A run freezes its upper bound at its start time (never in the future); later refreshes can extend October to November 1 exclusively.
- Prefer top archived scores, independently per subject/month. Initial cap: 150 usable unique images per subject/month. Scores are archive snapshots, not official Reddit top rankings. Fetch all pages before declaring a source/month complete. Recent scores are provisional.
- Fetch by subreddit and date, not mandatory title keywords. Retain lightweight candidate metadata, then hydrate ranked candidates for usable images. Skip NSFW, removed/deleted posts, videos and duplicate primary image URLs. Preserve spoiler flags as metadata, rather than excluding fandom announcements.
- Database dataset, taxonomy, crawl checkpoints, candidates and selected-image membership are versioned and additive. Existing crawl images are reused by ID/URL without deleting legacy data. Live feed and embedding notebook operate on the active dataset membership.
- One polite direct worker, request timeout/backoff, resumable month-sized windows (one task per subreddit/month, `limit=auto` pages; the archive cannot sort by score, so every month is fully scanned), persistent errors/heartbeat. Only the top 600 (4× cap) candidates per subject/month are retained. No public proxy fleet. Hidden background process writes logs and PID. Incomplete sources remain visibly incomplete and cannot silently publish a partial monthly ranking as complete.
- Persist multiple user-interest vectors keyed by subject, plus recent and negative vectors. Retrieve each strong interest separately rather than only the blended average. No item embeddings are generated during this task.

## Verification

Tests cover window boundaries, neutral titles, independent tags, flat depth, score selection, URL deduplication, resumable/failed pages, dataset isolation, and distinct-interest retrieval. Run existing feed regression tests and migration checks. Apply the additive migration, seed the catalog and sources, launch the worker, and verify an actual DB checkpoint/heartbeat and candidates. A running crawl is not a completed corpus.
